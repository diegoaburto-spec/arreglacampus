# ArreglaCampus (MVP v1.0)
Sistema web progresivo para el reporte y gestión de fallas de infraestructura en el Instituto Profesional Virginio Gómez.

## Requisitos de ejecución
- Navegador web moderno (Chrome, Edge, Firefox o Safari) con acceso a internet (para cargar estilos Tailwind CSS).
- No requiere instalación de base de datos ni credenciales personales externas.

## Instrucciones de ejecución
1. Descargar y descomprimir la carpeta del proyecto.
2. Abrir el archivo `index.html` directamente en cualquier navegador web (o mediante la extensión *Live Server* en Visual Studio Code).
